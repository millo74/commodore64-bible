# Benvenuto

**Ogni viaggio ha bisogno di un punto di partenza.**

Questo è il tuo.

La Commodore 64 Bible è stata progettata come una rete di Knowledge Trail, non come un libro tradizionale.

Non esiste un unico percorso attraverso il progetto.

Tuttavia, se questa è la tua prima visita, il seguente ordine di lettura è quello consigliato.
