# Stage 001 — Initial Asset Pack

This is the first visual asset pack for the initial drafting of Knowledge Trail Stage 001.

The SVG files are original educational illustrations created specifically for the Commodore 64 Bible.
They are deliberately conceptual: they help the reader build a mental model before introducing revision-specific hardware schematics.

## Suggested use

- `overview/c64_overview.svg` — opening visual / physical machine
- `diagrams/c64_architecture.svg` — Layer 3 conceptual architecture
- `diagrams/c64_motherboard_learning_map.svg` — motherboard orientation
- `chips/c64_chip_roles.svg` — Layer 1 specialist-team metaphor

External historical photographs and technical diagrams are listed in `metadata/SOURCES_AND_LICENSES.md`.
